# Calculadora de Notas Instituto i3

Aplicación web para ingresar el nombre de un estudiante y tres notas, calcular el promedio y mostrar si aprobó.

## Cómo ejecutar

Abre `index.html` en un navegador web. No requiere instalación.

## Regla de aprobación

- Nota mínima: `0.0`
- Nota máxima: `5.0`
- Se aprueba con promedio mayor o igual a `3.0`.
-Cada rama se integró a main mediante pull request y merge. Los commits registrados corresponden a las cargas de archivos y a los merges de cada rama.
## Archivos

- `index.html`: interfaz y formulario.
- `script.js`: cálculo, resultado y validaciones.
- `style.css`: diseño responsive.
- `ENTREGA.md`: investigación, reflexión y evidencias solicitadas.
